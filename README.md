# TipsWallet & TIPSPAY (Linux Mint Optimized)
TipsChain L1 (Chain ID: 19251925) projesi için boilerplate.

## Kurulum
1. Terminali açın.
2. `unzip TipsWallet_Linux.zip` komutuyla dosyaları çıkarın.
3. `cd tips-wallet` dizinine girin.
4. `npm install` ile bağımlılıkları yükleyin.

## Özellikler
- Non-Custodial mimari.
- Cloud Backup (Drive, Dropbox).
- Gasless Transaction (architect.tips).
